# KASC Pulse

Build a modern, production-quality College Attendance Management Web App using Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, Lucide React, and Framer Motion.

Theme:

- Clean, minimal, premium UI
- White background with blue (#2563EB) as the primary color
- Rounded cards (16px radius)
- Soft shadows
- Mobile-first responsive design
- Smooth animations
- Dark mode support
- Modern SaaS dashboard aesthetic

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
